# 세나 리버스 세팅 판정기

세븐나이츠 리버스 PVE(공성전 월~일, 강림) 콘텐츠별 목표 치확·치피·약확 계산기.

**바로 쓰기**: https://aceoberon.github.io/sknr-optimizer/

- **세팅** — 콘텐츠를 고르면 캐릭터별 목표 스탯과 운용(진형·속공·스킬 순서)을 한 화면에. 안전(치확 99) / 고점(이론상 최고) 두 모드.
- **목표** — 단위·강화 배분까지 상세, 내 스펙이 이상 대비 몇 %인지 평가.
- 입력값은 각자 브라우저에만 저장됩니다. 기기를 옮길 때는 **백업** 탭에서 내보내기·가져오기.

## 주의
- 아직 작업 중입니다. 캐릭터 기본 스탯 일부는 가정값이고, 딜 지분은 월·화·금만 실측입니다.
